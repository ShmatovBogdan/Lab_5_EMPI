# Лабораторна робота №4. Основи регресійного аналізу
Мета: засвоїти основи регресійного аналізу засобами Python.

# ЗАВДАННЯ
Дослідити методи регресійного аналізу на даних California Housing dataset засобами Python: виконати попередній аналіз і візуалізацію, побудувати парні та множинні лінійні моделі (МНК), а також моделі з регуляризацією (Lasso, Ridge, ElasticNet), оцінити їх точність і порівняти результати.

# ХІД РОБОТИ
Завантажено набір даних California Housing dataset та сформовано DataFrame із ознаками і цільовою змінною target. Виконано первинний аналіз даних: переглянуто перші рядки, типи змінних, статистичні характеристики та перевірено відсутність пропусків.

Побудовано матрицю кореляцій у вигляді теплової карти, що дозволило оцінити взаємозв’язки між ознаками та визначити найбільш впливові параметри для прогнозування ціни житла.

Далі проведено нормалізацію даних методом StandardScaler для приведення всіх ознак до єдиного масштабу.

Побудовано модель парної лінійної регресії з використанням ознаки MedInc. Дані розділено на навчальну та тестову вибірки. Після навчання моделі виконано прогнозування та розраховано метрики якості (R^2 та MSE). Побудовано графік залежності між реальною та прогнозованою величиною.

Після цього побудовано множинну лінійну регресію з використанням ознак MedInc, AveRooms та HouseAge. Проведено аналогічне навчання моделі, прогнозування та оцінку точності.

Додатково реалізовано моделі з регуляризацією: Ridge, Lasso та ElasticNet. Для кожної моделі отримано прогнози та обчислено метрики R^2 і MSE.

Проведено порівняння всіх моделей у вигляді таблиці, де оцінено якість кожного підходу. Завершально побудовано графік “реальні значення vs прогнозовані”, який дозволяє візуально оцінити точність моделі.
